# Baby shower de Elías

Invitación web con temática de dragones bebé.

- `index.html`: página lista para GitHub Pages.
- `web.template.html`: plantilla editable (datos del evento en el bloque "Datos editables" del primer script).
- `build.py`: incrusta los assets (`dragon-*.webp`, `lullaby.mp3`) y genera `index.html` y `babyshower-elias.html`.

Para actualizar: editar la plantilla, correr `python3 build.py` y hacer push.
